# WorldDex — мобильный справочник стран мира

Один экран поиска, одна карточка на страну и все базовые факты из единого официального
источника — сопоставимые между странами и доступные без интернета.

> **Статус:** Sprint 2 — интерактивный локальный каталог. К витрине добавлены поиск, фильтр
> по региону, выбор карточек со счётчиком и пользовательский hook `useCatalog`.
> Данные по-прежнему локальные: сеть, навигация и глобальное состояние подключаются позже.

## Проблема

Чтобы собрать базовые факты об одной стране, пользователь открывает несколько статей: столица —
в одной, население — в другой, классификация по уровню дохода — в третьей. Данные из разных
источников ссылаются на разные годы, поэтому две страны нельзя честно сравнить. И ничего из этого
не работает без сети.

## Решение

WorldDex показывает **одну карточку на страну** с полным набором фактов из **одного официального
источника** — World Bank Open Data. Все страны описаны одинаковым набором полей за один и тот же
период. Последние загруженные данные и встроенный резервный набор позволяют пользоваться
справочником offline.

## Целевая аудитория

**Основной сегмент** — студенты 1–2 курса и старшеклассники, готовящие доклады и практические
работы по географии, экономике и обществознанию. Работают с телефона, часто в дороге, им нужен
проверяемый факт здесь и сейчас, со ссылкой на источник.

**Дополнительный сегмент** — участники квизов и олимпиад по географии.

Продукт **не рассчитан** на аналитиков, которым нужны временные ряды по десяткам показателей и
выгрузка в CSV.

## Основной пользовательский сценарий

Студент готовит доклад про Японию, до начала семинара 2 минуты:

1. Открывает приложение → видит список стран.
2. Вводит `яп` / `jap` в поиск → список фильтруется по мере ввода.
3. Нажимает «Japan» → открывается карточка страны.
4. Видит флаг, столицу, регион, уровень дохода, население с годом наблюдения и координаты.
5. Возвращается назад → поисковый запрос сохранён.

Нужный факт получен менее чем за 30 секунд, без перехода в браузер. Если сети нет, шаг 1 отдаёт
данные из резервного источника с явной плашкой об этом.

## Границы MVP

**Входит:** список стран, поиск по названию, карточка страны, флаг, состояния загрузки и ошибки,
работа без сети.

**Не входит в первую версию:** авторизация, карта, графики динамики по годам, сравнение стран,
полная локализация, push-уведомления. Обоснование каждого отказа —
в [docs/product-concept.md](docs/product-concept.md#5-границы-mvp).

## Как устроена витрина

`Topic` — тип основной сущности справочника: обязательные `id` и `title`, содержательное
`description`, необязательное `imageUrl` и поля предметной области — столица, регион, уровень
дохода, население с годом наблюдения и коды ISO.

`TopicCard` — переиспользуемый компонент. Он не знает, откуда пришли данные: получает готовый
объект `Topic` через props и сообщает о нажатии через типизированный callback
`onPress: (topic: Topic) => void`. Необязательный prop `featured` включает укрупнённое
оформление первой карточки каталога, `selected` — отметку выбора. Если у объекта нет `imageUrl`, вместо флага
рисуется заглушка с кодом страны, и вёрстка не ломается.

`CatalogScreen` выводит карточки через `FlatList`: `renderItem` типизирован как
`ListRenderItem<Topic>`, `keyExtractor` возвращает стабильный `id` объекта, а не индекс массива.
Разметка карточки нигде не дублируется.

`useCatalog` — пользовательский hook, в котором живёт вся логика каталога: поисковый запрос,
выбранный регион, набор отмеченных карточек и производный от них видимый список. Экран получает
готовые данные и обработчики и занимается только отображением. Поиск отложен на 250 мс через
`useEffect` с зависимостью `[query]` и cleanup, который снимает таймер, — быстрый ввод не
оставляет лишних таймеров. Выбор хранится массивом `id` и обновляется иммутабельно: отметка
добавляется через `[...previous, id]`, снимается через `filter`, поэтому дубликаты невозможны.

## Как проверить

1. Запустить `npm start` и открыть приложение в Expo Go или нажать `w`, чтобы открыть в браузере.
2. Ввести `an` в поиск — список сузится, счётчик покажет «6 из 12». Регистр не важен:
   `JAPAN` и `japan` дают одинаковый результат. Поиск идёт по названию и столице.
3. Очистить поле — вернутся все 12 карточек.
4. Выбрать регион в ленте фильтров — останутся только его страны, счётчик обновится.
   Сбросить фильтр можно чипом «Все регионы» или ссылкой «сбросить фильтры».
5. Нажать на карточки — появится галочка, счётчик «Выбрано» вырастет. Повторное нажатие
   снимает отметку.
6. Ввести `zzz` — появится пустое состояние с объяснением и кнопкой «Сбросить фильтры».
