# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [sprint-1] — 09.09.2026

Статическая витрина и переиспользуемая `TopicCard`. Первый пользовательский экран справочника,
собранный на локальных данных без сети, навигации и глобального состояния.

### Добавлено

- `src/types/topic.ts` — тип `Topic`: обязательные `id` и `title`, содержательное `description`,
  необязательное `imageUrl` и поля предметной области (столица, регион, уровень дохода,
  население с годом наблюдения, коды ISO).
- `src/data/topics.ts` — файл локальных fixtures: 12 стран со стабильными уникальными `id`,
  данные подготовлены по резервному набору World Bank.
- `src/components/TopicCard.tsx` — переиспользуемый компонент карточки. Props типизированы:
  `topic`, callback `onPress: (topic: Topic) => void` и необязательный `featured`.
  Компонент не знает об источнике данных, `children` не используются за отсутствием
  необходимости. При отсутствии `imageUrl` рисуется заглушка с кодом страны.
- `src/screens/CatalogScreen.tsx` — экран каталога на `View`, `Text`, `Image`, `Pressable`
  и `StyleSheet`; карточки выводятся перебором fixtures, разметка не дублируется.
  Нажатие обновляет строку «Выбранная карточка».
- `src/lib/format.ts`, `src/theme.ts` — форматирование чисел и общие значения оформления.
- `assets/sprint-1.png` — демонстрационный артефакт спринта.

### Изменено

- `App.tsx` — вместо экрана-заглушки подключён экран каталога.
- `README.md` — статус спринта, скриншот витрины, структура проекта, раздел «Как устроена витрина».
- `docs/backlog.md` — перепланирование спринтов под методические указания: Sprint 1 и Sprint 2
  работают на локальных данных, сеть переезжает в Sprint 3. Добавлены US-10 и US-11.
- `docs/environment.md` — зафиксированы движок Hermes и проверка Fast Refresh.

### Зависимости

- `react-dom`, `react-native-web`, `@expo/metro-runtime` — запуск в браузере для снятия
  демонстрационного артефакта и быстрой проверки вёрстки.

### Проверено

- `tsc --noEmit` — без ошибок, `any` в коде нет.
- Нажатие на карточку вызывает callback: строка выбора меняется на «Australia · Canberra».
- Карточка без `imageUrl` (Canada) показывает заглушку `CAN`, компоновка не ломается.
- Fast Refresh: правка `title` в fixtures отражается на экране без перезагрузки приложения.

## [sprint-0] — 09.09.2026

Первый спринт: концепция продукта и подготовка проекта. Пользовательской функциональности нет —
инкремент состоит из проекта, документации и проверенного источника данных.

### Добавлено

- Проект React Native 0.86 / Expo SDK 57 на TypeScript (шаблон `blank-typescript`).
- `README.md` — описание продукта, тематика, аудитория, основной сценарий, состояние среды.
- `docs/product-concept.md` — проблема, идея, аудитория, сценарий, границы MVP, кандидат
  открытого API с ограничениями и резервным источником, риски.
- `docs/backlog.md` — product backlog из 9 пользовательских историй; для US-1 определено
  6 проверяемых критериев приёмки.
- `docs/environment.md` — версии инструментов, выполненные проверки, чек-лист готовности к Sprint 1.
- `docs/git-workflow.md` — процесс публикации спринта: ветка, pull request, тег.
- `assets/data/countries.fallback.json` — резервный источник данных, 12 стран, сгенерирован
  из реальных ответов World Bank API.
- `App.tsx` — экран-заглушка, подтверждающий работоспособность среды.
- Скрипты `npm run typecheck` и `npm run doctor`.

### Изменено

- `app.json` — название приложения `WorldDex` и описание продукта.
- `.gitignore` — добавлены `.env` и `.env.*` с исключением `.env.example`, чтобы секреты
  не попадали в репозиторий.

### Решения

- **Отказ от REST Countries.** Версия v3.1 задепрекейчена и возвращает ошибку вместо данных,
  а v5 требует регистрации и `Authorization: Bearer`. Выбран World Bank Indicators API v2 —
  без ключа и регистрации. Подробности — в `docs/product-concept.md`, п. 6.6.

### Осознанно не сделано

Сетевые запросы, навигация, глобальное состояние, база данных и полноценный интерфейс —
согласно ограничениям Sprint 0.
