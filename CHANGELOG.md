# Changelog

Номер версии растёт по времени, номер спринта обозначает тему работы. Поэтому Sprint 4
вышел раньше Sprint 3: сетевой каталог сдавался до навигации.

| Версия | Спринт | Что добавилось |
| --- | --- | --- |
| 0.4.0 | sprint-4 | загрузка из API |
| 0.3.0 | sprint-2 | поиск, фильтр, выбор |
| 0.2.0 | sprint-1 | витрина на локальных данных |
| 0.1.0 | sprint-0 | концепция и каркас |

## [0.4.0] — sprint-4 — 19.10.2026

Каталог перешёл с локальных данных на World Bank API.

### Добавлено

- `src/shared/api/transportService.ts` — единственное место с `fetch`: base URL, заголовок
  `Accept`, таймаут 10 секунд, связывание внешнего сигнала отмены с внутренним контроллером.
- `src/shared/api/errors.ts` — коды `http_error`, `not_found`, `invalid_id`, `network_error`,
  `timeout`, `cancel`, `parse_error`, `contract_error` и тексты для пользователя.
- `src/shared/api/logger.ts` — события `http.start`, `http.end` и `api.contract_error`
  с `requestId`, безопасным маршрутом, статусом, длительностью и исходом.
- `src/shared/api/requestGuard.ts` — счётчик актуальности, отбрасывает устаревшие ответы.
- `src/api/apiManager.ts` и `src/api/countries/` — методы `list`, `getById`, `getPopulation`,
  проверка DTO во время выполнения и перевод в модель `Topic`.
- `src/hooks/useTopic.ts` — загрузка данных карточки.
- `src/screens/TopicScreen.tsx` — экран страны с населением из отдельного запроса.
- Демонстрационные данные в `src/data/fixtures.ts`, включаются вручную и помечаются на экране.
- Тесты разбора ответа и защиты от устаревшего ответа, команда `npm test`.
- `docs/api.md`, `docs/architecture.md`, `docs/test-matrix.md`, `.env.example`.

### Изменено

- `useCatalog` работает с сетью: состояния загрузки, ошибки, пустого результата и дозагрузки,
  серверная пагинация и серверный фильтр по региону, поиск по загруженным записям,
  задержка поиска увеличена с 250 до 300 мс.
- Нажатие на карточку открывает страну, выбор карточки перенесён на долгое нажатие.
- `Topic`: поля `description`, `population` и `populationYear` стали необязательными —
  в ответе списка их нет.
- Карточка показывает заглушку, если флаг не загрузился.
- Версия приложения в `package.json` и `app.json` приведена к схеме выше.

### Исправлено

- Дозагрузка срабатывала сама при монтировании списка и при коротком результате поиска.
  Теперь она требует реальной прокрутки и отключена, пока активен поиск.

## [0.3.0] — sprint-2 — 09.09.2026

### Добавлено

- Hook `useCatalog`: поиск с задержкой 250 мс, фильтр по региону, выбор карточек.
- `SearchField` — поле поиска с кнопкой очистки.
- `RegionFilter` — фильтр по региону.
- Счётчики «N из 12» и «Выбрано», пустое состояние с кнопкой сброса.
- Скриншот и видео в `assets/`.
- `docs/retrospective.md`.

### Изменено

- `CatalogScreen` выводит карточки через `FlatList`.
- У `TopicCard` появился prop `selected`.

### После слияния

- Подключён ESLint и команда `npm run lint`.
- `RegionId` и `IncomeLevel` заменены на `enum RegionCode` и `enum IncomeLevel`.
- Выбранные карточки хранятся в `Set` вместо массива, добавлен бенчмарк `npm run bench`.
- `TopicCard`, `SearchField` и `RegionFilter` обёрнуты в `memo`.
- `expo` обновлён до 57.0.24.
