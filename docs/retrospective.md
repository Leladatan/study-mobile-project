# Ретроспектива

## Sprint 0

- **Сделано:** концепция, backlog, выбран и проверен API, создан проект.
- **Мешало:** первый выбранный API, REST Countries, оказался устаревшим — пришлось искать другой.
- **Долг:** названия стран только на английском.
- **Дальше:** первый экран на компонентах.

## Sprint 1

- **Сделано:** тип `Topic`, данные стран в отдельном файле, компонент `TopicCard`, экран каталога.
- **Мешало:** backlog не совпал с методичкой, загрузку из API пришлось перенести на Sprint 3.
  Тег `sprint-1` сначала был поставлен до слияния pull request.
- **Долг:** данные лежат в коде; `ScrollView` рисует все карточки сразу.
- **Дальше:** `FlatList`, поиск, фильтр и выбор.

## Sprint 2

- **Сделано:** `FlatList`, поиск с задержкой, фильтр по региону, выбор карточек, hook `useCatalog`.
- **Мешало:** задержку поиска нужно было сделать без лишних таймеров и бесконечного цикла.
  Тег `sprint-2` снова был поставлен раньше `git pull`.
- **Долг:** выбор не сохраняется после перезапуска приложения.
- **Дальше:** загрузка данных из World Bank API.
