## US-10. Витрина на локальных данных

Must · 3 SP · Sprint 1 · выполнено

Как пользователь, я хочу сразу видеть карточки стран, чтобы понимать, какие данные есть
в справочнике.

1. Данные лежат в отдельном файле и соответствуют типу `Topic`, у каждого объекта уникальный `id`.
2. Карточка — отдельный компонент `TopicCard`, данные он получает через props.
3. На экране не меньше трёх карточек, разметка карточки не копируется.
4. Нажатие на карточку вызывает типизированный callback.
5. Если у страны нет `imageUrl`, вместо флага показывается заглушка.

## US-11. Выбор карточек

Should · 2 SP · Sprint 2 · выполнено

Как пользователь, я хочу отмечать страны, чтобы держать нужные перед глазами.

1. Нажатие отмечает карточку, повторное нажатие снимает отметку.
2. Выбор обновляется без изменения старого состояния, дубликатов нет.
3. На экране виден счётчик выбранных.

После Sprint 4 отметка перенесена на долгое нажатие: обычное нажатие открывает карточку страны.

## US-1. Список стран из API

Must · 5 SP · Sprint 4 · выполнено

Как студент, я хочу сразу видеть список всех стран, чтобы не искать их в браузере.

1. Приложение запрашивает `GET /v2/country?format=json&page=N&per_page=50` и показывает список.
   Следующие страницы догружаются по прокрутке, признак окончания — `page >= pages`.
2. Группы стран (`region.id === "NA"`) в список не попадают, остаётся 217 стран.
3. В строке есть название и столица. Если столицы нет, выводится «Столица не указана».
4. Список отсортирован по названию.
5. Пока идёт загрузка, виден индикатор, пустой результат до конца запроса не показывается.
6. При ошибке сети или неправильном ответе показывается причина и кнопка «Повторить».

## US-2. Поиск по названию

Must · 3 SP · Sprint 2 · выполнено

Как студент, я хочу искать страну по части названия, чтобы не листать весь список.

1. Поиск ищет подстроку без учёта регистра.
2. Список обновляется по мере ввода.
3. Если ничего не нашлось, показывается «Ничего не найдено».
4. Кнопка очистки возвращает полный список.

После Sprint 4 поиск идёт по загруженным записям — у API нет серверного поиска по названию.
Приложение показывает это прямо на экране и даёт кнопку, которая догружает весь справочник.

## US-3. Карточка страны

Must · 5 SP · Sprint 4 · выполнено

Как студент, я хочу открыть страну и увидеть её данные на одном экране.

1. Нажатие на страну открывает её карточку.
2. В карточке есть название, столица, регион, уровень дохода, население и координаты.
3. При возврате к списку сохраняются запрос, фильтр и позиция прокрутки.
4. Карточка запрашивает свои данные сама, а не получает их из списка.

## US-4. Флаг страны

Should · 2 SP · Sprint 1 · выполнено

Как пользователь, я хочу видеть флаг, чтобы быстрее узнавать страну.

1. Флаг загружается по адресу `https://flagcdn.com/w320/{iso2}.png`.
2. Пока картинка грузится, на её месте блок того же размера.
3. Если картинки нет, показывается заглушка, вёрстка не ломается.

## US-5. Работа без сети

Must · 5 SP · Sprint 4 · частично

Как студент, я хочу пользоваться справочником без интернета.

1. При недоступности API можно вручную включить демонстрационные данные. **Сделано.**
2. Пока они показаны, видна метка «Демо-данные» и кнопка возврата к сети. **Сделано.**
3. Загруженный список сохраняется на устройстве и открывается без сети. **Не сделано.**

Сохранение на устройство требует хранилища и переносится в следующий спринт. Молча подменять
ответ сервера резервными данными нельзя: пользователь решит, что видит свежие данные.

## US-6. Фильтр по региону

Should · 3 SP · Sprint 2 · выполнено

Как пользователь, я хочу видеть страны одного региона.

1. Можно выбрать один из регионов World Bank.
2. Фильтр меняет список, счётчик показывает, сколько стран осталось.
3. Фильтр работает вместе с поиском.

После Sprint 4 фильтр уходит на сервер параметром `region`, смена региона сбрасывает страницу
и старую выдачу.

## US-7. Население из API

Should · 3 SP · Sprint 4 · выполнено

Как студент, я хочу видеть население с годом, чтобы правильно сослаться на данные.

1. При открытии карточки выполняется запрос
   `GET /v2/country/{ISO3}/indicator/SP.POP.TOTL?format=json&per_page=1&mrnev=1`.
2. Число выводится с разделителями и годом, например «123 366 734 чел. (2025)».
3. Если данных нет (`value: null`), выводится «нет данных», карточка при этом открывается.

## US-12. Навигация и прямые ссылки

Must · 5 SP · Sprint 3 · выполнено

Как пользователь, я хочу открывать карточку по ссылке и возвращаться назад привычным жестом.

1. Экраны разведены по маршрутам Expo Router, карточка живёт по адресу `/topic/{id}`.
2. Через адрес передаётся только `id`.
3. Неизвестный адрес открывает экран «не найдено».
4. Возврат сохраняет запрос, фильтр и позицию списка; если истории нет, есть кнопка «В каталог».

## US-8. Поиск по-русски

Could · 5 SP · не запланировано

Как пользователь, я хочу искать «Япония», а не «Japan». API отдаёт только английские названия,
поэтому нужен свой словарь «код страны → русское название».
