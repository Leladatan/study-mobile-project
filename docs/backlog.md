## US-10 — Витрина справочника на локальных данных `Must` `3 SP` `Sprint 1`

> **Как** пользователь, **я хочу** при запуске приложения сразу видеть карточки стран,
> **чтобы** оценить, какие факты справочник вообще показывает.

Критерии приёмки:
1. Данные вынесены в отдельный файл fixtures и соответствуют типу `Topic`; у каждого объекта
   стабильный уникальный `id`.
2. Карточка вынесена в переиспользуемый компонент `TopicCard`, который не знает об источнике
   данных и получает объект через props.
3. На экране отображается не менее трёх карточек, разметка карточки не продублирована.
4. Нажатие на карточку вызывает типизированный callback и меняет видимое состояние экрана.
5. Если у объекта нет `imageUrl`, вместо изображения выводится заглушка, вёрстка не ломается.

## US-11 — Выбор карточек и счётчик `Should` `2 SP` `Sprint 2`

> **Как** пользователь, **я хочу** отмечать интересные страны, **чтобы** держать их перед глазами
> при подготовке доклада.

Критерии приёмки:
1. Нажатие отмечает и снимает отметку с карточки; отмеченная карточка визуально отличается.
2. Состояние выбора обновляется иммутабельно, дубликаты в наборе исключены.
3. На экране виден счётчик отмеченных карточек, соответствующий состоянию.

## US-1 — Список стран `Must` `5 SP` `Sprint 1`

> **Как** студент, **я хочу** при открытии приложения сразу видеть список всех стран,
> **чтобы** не искать нужную страну в браузере.

### Критерии приёмки

1. **Загрузка данных.** При открытии экрана приложение выполняет запрос
   `GET https://api.worldbank.org/v2/country?format=json&per_page=300`; при успешном ответе
   на экране отображается список стран.

2. **Фильтрация агрегатов.** Записи, у которых `region.id === "NA"` (агрегаты вида
   «Africa Eastern and Southern», «High income»), в список не попадают. На дату проверки
   09.09.2026 API отдаёт 295 записей, из которых 78 — агрегаты, поэтому в списке
   отображается **217 стран и территорий**.

3. **Содержимое строки.** Каждая строка списка содержит название страны (`name`) и её
   столицу (`capitalCity`). Если `capitalCity` — пустая строка (так API отдаёт данные для
   ряда территорий), вместо неё выводится прочерк «—», и строка не ломает вёрстку.

4. **Сортировка.** Список отсортирован по названию страны по возрастанию, сортировка
   устойчива и не зависит от порядка записей в ответе API.

5. **Состояние загрузки.** Пока запрос не завершён, на экране виден индикатор загрузки;
   после завершения индикатор пропадает. Пустой белый экран в этот момент недопустим.

6. **Состояние ошибки.** Если запрос завершился ошибкой сети, истёк таймаут или тело ответа
   не является ожидаемым массивом из двух элементов (см. ограничение «ошибки приходят с
   HTTP 200» в [product-concept.md](./product-concept.md#64-ограничения-и-как-их-обходим)),
   пользователю показывается сообщение об ошибке и кнопка «Повторить», а не пустой список.

### Definition of Done истории

- [ ] `npx tsc --noEmit` проходит без ошибок.
- [ ] Сценарий вручную проверен на Android-устройстве или эмуляторе.
- [ ] Проверено поведение при выключенной сети (авиарежим).
- [ ] Изменения влиты в `main` через pull request.

## US-2 — Поиск страны по названию `Must` `3 SP` `Sprint 1`

> **Как** студент, **я хочу** отфильтровать список по части названия,
> **чтобы** не прокручивать 217 строк.

Критерии приёмки:
1. Ввод в поле поиска фильтрует список по вхождению подстроки, без учёта регистра.
2. Список обновляется по мере ввода, без нажатия отдельной кнопки.
3. Если совпадений нет, показывается сообщение «Ничего не найдено», а не пустой экран.
4. Кнопка очистки возвращает полный список.

## US-3 — Карточка страны `Must` `5 SP` `Sprint 2`

> **Как** студент, **я хочу** открыть страну и увидеть её основные факты на одном экране,
> **чтобы** собрать данные для доклада за один заход.

Критерии приёмки:
1. Нажатие на строку списка открывает карточку выбранной страны.
2. В карточке выведены: название, столица, регион, уровень дохода, координаты.
3. Возврат к списку сохраняет ранее введённый поисковый запрос и позицию прокрутки.

## US-4 — Флаг страны `Should` `2 SP` `Sprint 2`

> **Как** пользователь, **я хочу** видеть флаг страны, **чтобы** быстрее узнавать её визуально.

Критерии приёмки:
1. В карточке отображается флаг по адресу `https://flagcdn.com/w320/{iso2Code в нижнем регистре}.png`.
2. Пока изображение грузится, на его месте показан плейсхолдер фиксированного размера — карточка
   не «прыгает».
3. Если изображение не загрузилось, вместо него остаётся плейсхолдер, карточка не падает.

## US-5 — Работа без сети и резервный источник `Must` `5 SP` `Sprint 2`

> **Как** студент в аудитории без интернета, **я хочу** пользоваться справочником offline,
> **чтобы** приложение было полезно именно тогда, когда нужно.

Критерии приёмки:
1. Успешно загруженный список стран сохраняется на устройстве и используется при следующем
   запуске без сети.
2. Если кэша нет и сеть недоступна, используется `assets/data/countries.fallback.json`.
3. При работе на резервных данных в интерфейсе видна плашка с указанием источника и даты
   актуальности данных из поля `meta.generatedAt`.

## US-6 — Фильтр по региону `Should` `3 SP` `Sprint 3`

> **Как** пользователь, **я хочу** отобрать страны одного региона, **чтобы** готовиться к теме
> по конкретной части света.

Критерии приёмки:
1. Доступен выбор одного из 7 регионов World Bank (`region.id`: EAS, ECS, LCN, MEA, NAC, SAS, SSF).
2. Выбранный регион фильтрует список; счётчик показывает количество найденных стран.
3. Фильтр по региону и текстовый поиск работают совместно.

## US-7 — Численность населения в карточке `Should` `3 SP` `Sprint 3`

> **Как** студент, **я хочу** видеть население страны с указанием года,
> **чтобы** корректно сослаться на данные в работе.

Критерии приёмки:
1. При открытии карточки выполняется запрос
   `GET /v2/country/{ISO3}/indicator/SP.POP.TOTL?format=json&mrv=1`.
2. Число отображается с разделителями разрядов и годом наблюдения (например, «143 513 328 (2025)»).
3. Если показатель отсутствует (`value: null`), выводится «нет данных», карточка не падает.

## US-8 — Поиск по русскому названию страны `Could` `5 SP` `Backlog`

> **Как** русскоязычный пользователь, **я хочу** искать «Япония», а не «Japan».

World Bank API отдаёт только английские названия, поэтому история требует собственного словаря
соответствий ISO-3 → русское название. Вынесена за пределы MVP осознанно.
