# API справочника

Приложение берёт данные из World Bank Indicators API v2. Ключ не нужен, авторизации нет,
лицензия данных — CC BY-4.0.

## Параметры подключения

| Параметр | Значение |
| --- | --- |
| Base URL | `https://api.worldbank.org/v2` |
| Протокол | HTTPS |
| Метод | GET |
| Заголовок запроса | `Accept: application/json` |
| Авторизация | не требуется |
| Лимит запросов | в документации не объявлен |
| CORS | `Access-Control-Allow-Origin: *`, поэтому работает и в браузере |
| Таймаут в приложении | 10 секунд |

Base URL хранится в одном месте — в `src/shared/api/transportService.ts`. Его можно переопределить
переменной `EXPO_PUBLIC_API_BASE_URL`, пример лежит в `.env.example`.

Важно: переменные с префиксом `EXPO_PUBLIC_` попадают в собранное приложение, их видно в бандле.
Это годится только для публичной конфигурации. Секретный ключ так хранить нельзя — ни в исходниках,
ни в сборке, ни в логах.

## Используемые запросы

### Список стран

```
GET /country?format=json&page=1&per_page=50
```

Дополнительный параметр `region=ECS` ограничивает выборку одним регионом.

Ответ — массив из двух элементов: сначала метаданные, потом записи.

```json
[
  { "page": 1, "pages": 6, "per_page": "50", "total": 296 },
  [
    {
      "id": "JPN",
      "iso2Code": "JP",
      "name": "Japan",
      "region": { "id": "EAS", "value": "East Asia & Pacific" },
      "incomeLevel": { "id": "HIC", "value": "High income" },
      "capitalCity": "Tokyo",
      "longitude": "139.77",
      "latitude": "35.67"
    }
  ]
]
```

Обязательные поля для приложения: `id`, `name`, `iso2Code`, `capitalCity`, `region.id`,
`region.value`, `incomeLevel.value`. Признак окончания выдачи — `page >= pages`.

### Одна страна

```
GET /country/JPN?format=json
```

Тот же формат, в списке записей один элемент.

### Население

```
GET /country/JPN/indicator/SP.POP.TOTL?format=json&per_page=1&mrnev=1
```

```json
[
  { "page": 1, "pages": 1, "per_page": 1, "total": 1 },
  [{ "countryiso3code": "JPN", "date": "2025", "value": 123366734 }]
]
```

`mrnev=1` просит последнее непустое наблюдение. Значение может быть `null` — это не ошибка,
приложение показывает «нет данных».

## Команды для проверки вне приложения

Команды записаны для bash. В PowerShell используйте `curl.exe` и одну строку без переносов.

```bash
curl -i --max-time 10 \
  "https://api.worldbank.org/v2/country?format=json&page=1&per_page=3"

curl -i --max-time 10 \
  "https://api.worldbank.org/v2/country/JPN?format=json"

curl -i --max-time 10 \
  "https://api.worldbank.org/v2/country/JPN/indicator/SP.POP.TOTL?format=json&per_page=1&mrnev=1"
```

Проверка заведомо неверного маршрута:

```bash
curl -i --max-time 10 "https://api.worldbank.org/v2/nosuchpath?format=json"
```

## Что показали проверки

Проверено 18.10.2026 командой `curl`.

| Запрос | Статус | Тело |
| --- | --- | --- |
| Список | 200 | `[meta, data]`, `total: 296` |
| Страна по id | 200 | одна запись |
| Население | 200 | `value: 123366734`, `date: "2025"` |
| Неверный маршрут `/nosuchpath` | **404** | HTML-страница ошибки |
| Неверный id `/country/ZZZ` | **200** | `[{"message":[{"id":"120","key":"Invalid value"}]}]` |

Последняя строка — главная особенность этого API. **На неизвестный код страны сервер отвечает
не 404, а 200 с телом ошибки.** Поэтому «запись не найдена» определяется не по статусу, а по форме
ответа: если в теле вместо пары «метаданные + записи» лежит объект с полем `message`, приложение
возвращает ошибку `not_found`.

## Состав справочника

В выдаче 296 строк, но не все они страны:

| Что | Сколько | Признак |
| --- | --- | --- |
| Страны и территории | 217 | `region.id` — один из 7 кодов региона |
| Агрегаты: регионы, группы по доходу | 79 | `region.id === "NA"` |

Агрегаты вроде «Africa Eastern and Southern» или «High income» отфильтровываются в модуле API,
до того как данные попадут на экран. Это не ошибка контракта, а штатная часть ответа.

Коды регионов в ответе совпадают с `enum RegionCode`: `EAS`, `ECS`, `LCN`, `MEA`, `NAC`, `SAS`,
`SSF`. Уровни дохода совпадают с `enum IncomeLevel`: `High income`, `Upper middle income`,
`Lower middle income`, `Low income`. Если сервер пришлёт незнакомый код, приложение не подставит
значение по умолчанию, а вернёт `contract_error` — молчаливая подмена скрыла бы изменение API.

Шесть стран в справочнике не имеют столицы (Channel Islands, Gibraltar, Hong Kong SAR и другие).
Пустая строка в `capitalCity` — допустимое значение, приложение пишет «Столица не указана».

## Стратегия поиска и границы данных

У этого API **нет серверного поиска по названию**. Поэтому роли распределены так:

| Что | Где выполняется |
| --- | --- |
| Постраничная выдача | на сервере, параметры `page` и `per_page` |
| Фильтр по региону | на сервере, параметр `region` |
| Поиск по названию и столице | в приложении, по уже загруженным записям |

Из этого следует честное ограничение: **поиск видит только загруженные страницы, а не всю базу.**
Приложение не делает вид, что ищет по всему справочнику. Когда поиск активен, а загружены не все
страницы, на экране появляется строка «Поиск идёт по загруженным записям» с кнопкой, которая
догружает весь справочник одним запросом (`per_page=400`). После этого поиск работает по всем
217 странам, и счётчик показывает «Найдено N из 217».

Догрузка по прокрутке при активном поиске отключена намеренно: отфильтрованный список короче
экрана, и список начал бы подгружать страницы сам, без участия пользователя.

## Флаги

Картинки флагов берутся с [flagcdn.com](https://flagcdn.com) по коду `iso2Code`:
`https://flagcdn.com/w320/jp.png`. Это отдельный источник, не World Bank. Если картинка не
загрузилась, карточка показывает заглушку с кодом страны.
