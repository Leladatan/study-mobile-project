# Концепция WorldDex

## О продукте

| | |
| --- | --- |
| Название | WorldDex |
| Тема | Страны мира: столица, регион, население, уровень дохода, флаг |
| Платформа | Android (основная), iOS и браузер |
| Стек | React Native 0.86, Expo SDK 57, TypeScript |

## Проблема

Чтобы собрать базовые факты об одной стране, приходится открывать несколько страниц: столица
в одной статье, население в другой, уровень дохода в третьей. У разных источников разные годы
и методики, поэтому страны трудно сравнивать между собой. Без интернета ничего не найти.

## Идея

Одна карточка на страну, все данные из одного источника — World Bank Open Data. У всех стран
одинаковый набор полей за один период, поэтому их можно сравнивать. Если сети нет, приложение
показывает сохранённые или резервные данные.

## Аудитория

- **Основная:** студенты 1–2 курса и старшеклассники, которые готовят доклады по географии,
  экономике и обществознанию. Работают с телефона, им нужен быстрый факт и ссылка на источник.
- **Дополнительная:** участники викторин и олимпиад по географии.
- **Не для:** аналитиков, которым нужны временные ряды и выгрузка в CSV. Для этого есть
  World Bank DataBank.

## Основной сценарий

Студент готовит доклад про Японию, до семинара две минуты.

| Шаг | Пользователь | Приложение |
| --- | --- | --- |
| 1 | Открывает приложение | Показывает список стран по алфавиту |
| 2 | Вводит `jap` в поиск | Фильтрует список по мере ввода |
| 3 | Нажимает на Japan | Открывает карточку страны |
| 4 | Читает карточку | Флаг, столица, регион, уровень дохода, население с годом, координаты |
| 5 | Возвращается назад | Список и запрос сохранены |

Если сети нет, на шаге 1 приложение берёт резервные данные и показывает об этом плашку.

## Границы MVP

**Входит:**

- список стран из World Bank API;
- поиск по названию без учёта регистра;
- фильтр по региону;
- карточка страны с флагом и основными фактами;
- состояния загрузки, пустого результата и ошибки;
- работа без сети на резервных данных.

**Не входит:**

| Функция | Почему |
| --- | --- |
| Авторизация | Данные открытые, личный кабинет не нужен |
| Карта | Сложно и не нужно, чтобы найти факт |
| Графики по годам | Это уже аналитика и другая аудитория |
| Сравнение двух стран | Можно добавить позже |
| Русские названия стран | API отдаёт только английские, нужен свой словарь (US-8) |
| Push-уведомления, избранное с синхронизацией | Не влияют на основной сценарий |

## Источник данных

### API

| | |
| --- | --- |
| Название | World Bank Indicators API v2 |
| Документация | https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api-documentation |
| Формат запросов | https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures |
| Базовый адрес | `https://api.worldbank.org/v2/` |
| Доступ | HTTP GET с параметром `format=json`, ключ и регистрация не нужны |
| Лицензия | CC BY-4.0 |

### Нужные запросы

| Что | Запрос | Поля |
| --- | --- | --- |
| Список стран | `GET /v2/country?format=json&per_page=300` | `id`, `iso2Code`, `name`, `region`, `incomeLevel`, `capitalCity`, `latitude`, `longitude` |
| Одна страна | `GET /v2/country/JPN?format=json` | те же поля |
| Страны региона | `GET /v2/country?format=json&region=ECS` | список стран |
| Население | `GET /v2/country/JPN/indicator/SP.POP.TOTL?format=json&mrv=1` | `value`, `date` |
| Флаг | `GET https://flagcdn.com/w320/jp.png` | картинка по `iso2Code` |

Ответ API — массив из двух элементов: сначала информация о страницах, потом данные.

```json
[
  { "page": 1, "pages": 1, "per_page": "300", "total": 295 },
  [
    {
      "id": "JPN",
      "iso2Code": "JP",
      "name": "Japan",
      "region": { "id": "EAS", "value": "East Asia & Pacific" },
      "incomeLevel": { "id": "HIC", "value": "High income" },
      "capitalCity": "Tokyo"
    }
  ]
]
```

### Ограничения

1. Из 295 записей 78 — не страны, а группы вроде «High income». Их отсекаем по
   `region.id === "NA"`, остаётся 217 стран.
2. Ошибки приходят с кодом 200: запрос `/v2/country/ZZZ` возвращает 200 и текст ошибки в теле.
   Поэтому проверять нужно само тело ответа, а не только статус.
3. По умолчанию на странице 50 записей, поэтому передаём `per_page=300`.
4. У сервиса нет гарантий доступности — нужны кэш и резервные данные.
5. Флагов в API нет — берём их с flagcdn.com.
6. Названия стран только на английском, поиск по-русски пока не работает.
7. Население запрашивается отдельно, поэтому делаем этот запрос только при открытии карточки.

### Резервные данные

Файл [assets/data/countries.fallback.json](../assets/data/countries.fallback.json) — 12 стран
со всеми полями карточки. Данные взяты из настоящих ответов API, в секции `meta` записаны адреса
запросов, дата и лицензия. Используется, когда нет сети или API не ответил.

### Проверка API

Сначала рассматривался REST Countries v3.1, но он устарел: на запрос
`GET https://restcountries.com/v3.1/name/japan` приходит код 200 и сообщение, что эта версия
больше не поддерживается. Новая версия v5 требует регистрацию и ключ, поэтому выбран World Bank API.

Проверка World Bank API 09.09.2026:

| Запрос | Результат |
| --- | --- |
| `/v2/country?format=json&per_page=300` | 200, 295 записей, из них 217 стран |
| `/v2/country/RUS?format=json` | 200, столица Moscow |
| `/v2/country?format=json&region=ECS` | 200, 58 стран |
| `/v2/country/RUS/indicator/SP.POP.TOTL?format=json&mrv=1` | 200, 143 513 328 за 2025 год |
| `/v2/country/ZZZ?format=json` | 200, ошибка в теле ответа |
| `https://flagcdn.com/w320/ru.png` | 200, картинка PNG |

## Риски

| Риск | Что делаем |
| --- | --- |
| API станет платным или закроется | Резервный JSON в репозитории, логика данных отделена от экранов |
| Поиск по-русски не работает | Вынесено в backlog, US-8 |
| API отвечает медленно | Кэш на устройстве и индикатор загрузки |
| MVP разрастается | Границы зафиксированы выше |
