## 1. Проблема

Чтобы получить сверенный набор фактов об одной стране (столица, регион, группа по уровню дохода,
численность населения, координаты, флаг), пользователь сегодня открывает Википедию или поисковую
выдачу и вручную собирает данные из разных мест.

Три конкретных следствия:

1. **Данные разрознены.** Столица — в одной карточке, население — в другой, классификация по
   уровню дохода — в третьей статье. На телефоне это 3–5 переходов и постоянный зум.
2. **Данные не сопоставимы между странами.** Разные статьи ссылаются на разные годы и разные
   методики подсчёта населения, поэтому сравнить две страны «как есть» нельзя.
3. **Ничего не работает без сети.** В аудитории, метро или на выезде справка недоступна ровно
   тогда, когда нужна.

## 2. Идея продукта

WorldDex — мобильный справочник, который показывает **одну карточку на страну** с полным набором
базовых фактов из **единого официального источника** — World Bank Open Data. Все страны описаны
одинаковым набором полей за один и тот же период, поэтому их можно честно сравнивать. Последние
загруженные данные и встроенный резервный набор позволяют пользоваться справочником без сети.

Формула ценности: **один экран поиска → одна карточка → все базовые факты, сопоставимые между
странами и доступные offline.**

## 3. Целевая аудитория

### Основной сегмент

Студенты 1–2 курса и старшеклассники, которые готовят доклады, семинары и практические работы по
географии, экономике и обществознанию.

- Работают преимущественно с телефона, часто в дороге и в перерывах между парами.
- Им нужен факт «здесь и сейчас», а не глубокая аналитика.
- Важна корректная ссылка на источник — работу проверяет преподаватель.

### Дополнительный сегмент

Участники квизов, викторин и олимпиад по географии: сценарий тот же (быстрый поиск факта),
но выше требование к скорости отклика.

### Кого продукт НЕ обслуживает

Исследователи и аналитики, которым нужны временные ряды по десяткам показателей, выгрузка в
CSV/Excel и построение графиков. Для них существуют полноценные инструменты World Bank DataBank;
конкурировать с ними WorldDex не планирует.

## 4. Основной пользовательский сценарий

**Действующее лицо:** студент, готовит доклад про Японию, у него 2 минуты до начала семинара.

| Шаг | Действие пользователя | Ответ системы |
| --- | --- | --- |
| 1 | Открывает приложение | Показан список стран, отсортированный по названию |
| 2 | Вводит в поле поиска `яп` / `jap` | Список фильтруется по мере ввода |
| 3 | Нажимает на строку «Japan» | Открывается карточка страны |
| 4 | Читает карточку | Флаг, столица, регион, уровень дохода, население с годом наблюдения, координаты |
| 5 | Возвращается назад | Список и введённый поисковый запрос сохранены |

**Итог сценария:** нужный факт получен менее чем за 30 секунд и без единого перехода в браузер.

**Альтернативный ход (нет сети):** на шаге 1 система показывает данные из резервного набора и
выводит явную плашку «Данные из резервного источника, обновлены <дата>».

## 5. Границы MVP

### Входит в MVP (Sprint 1–3)

- Список всех стран, полученный из World Bank API.
- Поиск по названию страны (подстрока, регистронезависимый).
- Карточка страны: флаг, столица, регион, уровень дохода, население, координаты.
- Состояния загрузки, пустого результата и ошибки сети.
- Резервный источник данных при недоступности API.

### Сознательно НЕ входит в первую версию

| Отказались от | Почему |
| --- | --- |
| Авторизация и профиль пользователя | Справочник читает открытые данные, персонализация не нужна |
| Карта и геовизуализация | Дорогая интеграция, не входит в основной сценарий «найти факт» |
| Графики динамики показателей по годам | Уводит продукт в аналитику — это чужой сегмент (см. п. 3) |
| Сравнение двух стран рядом | Полезно, но не блокирует основной сценарий; кандидат на Sprint 4+ |
| Полная локализация интерфейса | В MVP — русский интерфейс, названия стран на английском, как их отдаёт API |
| Push-уведомления, офлайн-редактирование, избранное с синхронизацией | Не влияют на ценность MVP |

## 6. Кандидат открытого API

### 6.1 Итоговый выбор

| Параметр | Значение |
| --- | --- |
| **Название** | World Bank Indicators API v2 (эндпоинты `country` и `indicator`) |
| **Документация** | https://datahelpdesk.worldbank.org/knowledgebase/articles/889392-about-the-indicators-api-documentation |
| **Структура запросов** | https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures |
| **Базовый URL** | `https://api.worldbank.org/v2/` |
| **Способ доступа** | HTTP GET, без API-ключа, без регистрации, без заголовка `Authorization`. Формат задаётся параметром `?format=json` |
| **Лицензия данных** | CC BY-4.0, World Bank Open Data — https://datacatalog.worldbank.org/public-licenses |

### 6.2 Используемые эндпоинты и данные

| Назначение | Запрос | Что берём |
| --- | --- | --- |
| Список стран | `GET /v2/country?format=json&per_page=300` | `id` (ISO-3), `iso2Code`, `name`, `region`, `incomeLevel`, `capitalCity`, `latitude`, `longitude` |
| Одна страна | `GET /v2/country/JPN?format=json` | то же для карточки |
| Фильтр по региону | `GET /v2/country?format=json&region=ECS` | список стран региона |
| Население | `GET /v2/country/JPN/indicator/SP.POP.TOTL?format=json&mrv=1` | `value` (численность), `date` (год наблюдения) |
| Флаг страны | `GET https://flagcdn.com/w320/jp.png` | PNG-изображение по коду `iso2Code` в нижнем регистре |

Флаги World Bank API не отдаёт, поэтому изображения берутся с **flagcdn.com** — бесплатного
статического CDN без ключа и регистрации, работающего по кодам ISO 3166-1 alpha-2, которые
приходят в поле `iso2Code`.

### 6.3 Формат ответа

Ответ — массив из двух элементов: метаданные пагинации и массив данных.

```json
[
  { "page": 1, "pages": 1, "per_page": "300", "total": 295 },
  [
    {
      "id": "JPN",
      "iso2Code": "JP",
      "name": "Japan",
      "region":      { "id": "EAS", "value": "East Asia & Pacific" },
      "incomeLevel": { "id": "HIC", "value": "High income" },
      "capitalCity": "Tokyo",
      "longitude": "139.770",
      "latitude": "35.670"
    }
  ]
]
```

### 6.4 Ограничения и как их обходим

| Ограничение | Влияние на продукт | Решение |
| --- | --- | --- |
| В ответе `/country` **295 записей, из них 78 — агрегаты** (регионы и группы доходов вроде «Africa Eastern and Southern»), реальных стран и территорий — **217** | Без фильтрации пользователь увидит в списке несуществующие «страны» | Отбрасываем записи с `region.id === "NA"` |
| **Ошибки возвращаются с HTTP-статусом 200.** Например, `/v2/country/ZZZ?format=json` отдаёт `200` и тело `[{"message":[{"id":"120","key":"Invalid value",...}]}]` | Стандартная проверка `response.ok` не поймает ошибку | Проверяем форму тела ответа, а не только HTTP-статус |
| Пагинация по умолчанию — 50 записей на страницу | Неполный список при наивном запросе | Явно передаём `per_page=300` |
| Официальных лимитов запросов в документации нет, но сервис публичный и не гарантирует SLA | Возможны таймауты и деградация | Кэшируем ответ на устройстве, показываем последние загруженные данные |
| Нет флагов, валют и языков | Карточка была бы визуально бедной | Флаги — с flagcdn.com; валюты и языки в MVP не показываем |
| Названия стран только на английском (`Russian Federation`, а не `Россия`) | Русскоязычный поиск не сработает | В MVP ищем по английскому названию; русские названия — кандидат на бэклог (US-8) |
| Население — отдельный запрос к `indicator`, а не поле страны | +1 сетевой запрос на карточку | Запрашиваем население только при открытии карточки |

### 6.5 Резервный источник

**Файл:** [`assets/data/countries.fallback.json`](../assets/data/countries.fallback.json)

- Содержит 12 стран с полным набором полей карточки.
- **Сгенерирован из реальных ответов World Bank API**, данные не вводились вручную; в секции
  `meta` указаны исходные URL, индикатор населения, дата генерации и лицензия.
- Используется в двух случаях: устройство offline и API вернул ошибку или не ответил.
- При использовании резерва интерфейс обязан явно сообщать об этом пользователю (см. US-5).

Резервный источник **дополняет** основной API, а не заменяет его: он покрывает только
демонстрационную выборку стран и нужен, чтобы приложение оставалось работоспособным на защите
и в аудитории без стабильного интернета.

### 6.6 Проверка кандидата (выполнена 09.09.2026)

Изначально в качестве кандидата рассматривался **REST Countries v3.1** — популярный в учебных
проектах открытый API. Живая проверка показала, что использовать его нельзя:

```
GET https://restcountries.com/v3.1/name/japan
HTTP 200
{ "success": false, "data": null,
  "errors": [{ "message": "This API version has been deprecated.
     Please visit https://restcountries.com/docs/countries/legacy-api-deprecation
     to migrate to our new version (v5)." }] }
```

Актуальная версия v5 переехала на `https://api.restcountries.com/countries/v5/` и **требует
регистрации и заголовка `Authorization: Bearer <ключ>`**, а демонстрационный ключ `rc_live_demo`
возвращает не реальные данные, а один фиксированный пример. Это противоречит ограничению спринта
«не размещать API-ключи и другие секреты в репозитории» и усложняет сдачу работы, поэтому
кандидат был заменён на World Bank API.

Результаты проверки итогового кандидата:

| Запрос | Статус | Результат |
| --- | --- | --- |
| `/v2/country?format=json&per_page=300` | 200 | 295 записей, из них 217 стран |
| `/v2/country/RUS?format=json` | 200 | `capitalCity: "Moscow"`, `region: Europe & Central Asia`, `incomeLevel: High income` |
| `/v2/country?format=json&region=ECS&per_page=2` | 200 | 58 стран в регионе, пагинация работает |
| `/v2/country/RUS/indicator/SP.POP.TOTL?format=json&mrv=1` | 200 | `143 513 328` за 2025 год, `lastupdated: 2026-07-13` |
| `/v2/country/ZZZ?format=json` | 200 | тело с `message.key = "Invalid value"` — подтверждает ограничение из п. 6.4 |
| `https://flagcdn.com/w320/{ru,br,gb,jp}.png` | 200 | корректные PNG (сигнатура `89 50 4E 47`) |

**Вывод:** источник данных доступен, не требует ключа, покрывает все поля карточки из основного
сценария и пригоден для реализации MVP.

## 7. Риски

| Риск | Вероятность | Влияние | Реакция |
| --- | --- | --- | --- |
| Публичный API станет платным или закроется (как это произошло с REST Countries) | Средняя | Высокое | Резервный JSON в репозитории; слой доступа к данным изолирован, чтобы источник можно было заменить |
| Английские названия стран мешают русскоязычному поиску | Высокая | Среднее | Явно вынесено в бэклог как US-8, а не замалчивается |
| Медленный отклик публичного сервиса | Средняя | Среднее | Кэш на устройстве + видимое состояние загрузки |
| Переоценка объёма MVP | Средняя | Высокое | Жёстко зафиксированные границы MVP в п. 5 |
