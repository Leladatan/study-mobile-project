## Metro и Hermes

- **Metro** собирает код проекта в один бандл и отдаёт его на телефон или в браузер. Когда файл
  меняется, Metro пересобирает только его — на этом работает Fast Refresh.
- **Hermes** — движок JavaScript, который выполняет бандл на телефоне. В `app.json` движок
  не указан, поэтому используется Hermes по умолчанию. Это видно в адресе бандла:
  `transform.engine=hermes`.

Коротко: Metro собирает код на компьютере, Hermes выполняет его на устройстве. Ошибки сборки
приходят от Metro, ошибки во время работы — из Hermes.

Fast Refresh проверен: после изменения `title` в `src/data/topics.ts` экран обновился
без перезапуска.

## Известные проблемы

**Телефон не подключается при включённом VPN.** Expo может подставить в QR-код адрес VPN,
до которого телефон не достучится. Нужно выключить VPN или указать локальный IP компьютера:

```powershell
$env:EXPO_PACKAGER_HOSTNAME = "192.168.x.x"; npm start
```

**Metro падает с `EINVAL: readlink`.** Проект лежит в OneDrive, и после `npm install` Metro
не может прочитать часть файлов из старого кэша. Помогает запуск с очисткой кэша:

```bash
npx expo start --clear
```

**Git не удаляет папку при смене ветки.** Папку держит OneDrive. Нужно поставить синхронизацию
на паузу. Надёжнее всего перенести проект из OneDrive, например в `C:\dev\worlddex`.
