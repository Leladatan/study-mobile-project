## 4. Целевая платформа и запуск

**Основная платформа:** Android. iOS и Web поддерживаются Expo и используются как вспомогательные
среды отладки.

| Способ запуска | Команда | Что требуется |
| --- | --- | --- |
| Физическое устройство | `npm start`, затем сканировать QR-код | приложение **Expo Go** на телефоне, телефон и ПК в одной сети Wi-Fi |
| Android-эмулятор | `npm run android` | Android Studio с настроенным AVD и переменной `ANDROID_HOME` |
| Браузер | `npm run web` | ничего дополнительно |

Рекомендуемый для этого проекта путь — **Expo Go на физическом Android-устройстве**: он не требует
установки Android Studio и даёт самый быстрый цикл обратной связи.

> Запуск на устройстве выполняется вручную и подтверждается скриншотом в отчёте. Скриншот
> экрана-заглушки — единственное визуальное подтверждение, требуемое в Sprint 0.
