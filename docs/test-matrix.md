Среда: Windows 11 Pro, Expo Web, Microsoft Edge, `npm run web`, дата 19.10.2026.
Ошибки сети воспроизводились подменой ответа в инструментах разработчика браузера,
тестовый режим отделён от обычного — приложение об этой подмене не знает.

## Ошибки и восстановление

| Сценарий | Как воспроизвести | Ожидалось | Получилось |
| --- | --- | --- | --- |
| Нет сети | отключить сеть до запроса | понятная причина, `status: null` | «Нет связи с сервером», `outcome: network_error`, `status: null`, `durationMs: 27` |
| HTTP 404 | подменить ответ на 404 | ошибка со статусом, не сетевой отказ | «Сервер ответил ошибкой 404», `outcome: http_error`, `status: 404` |
| Невалидный JSON | ответ 200 с обрезанным телом | разбор не прошёл, экран цел | «Ответ сервера не удалось разобрать», `outcome: parse_error` при `status: 200` |
| Некорректный DTO | ответ 200, `name: null` | `contract_error`, интерфейс не падает | отдельное сообщение, лог `api.contract_error` с `field: "country.name"`, транспорт при этом `outcome: success` |
| Неизвестный код | ответ 200 с телом `message` | «записи нет», а не ошибка формата | «Такой записи нет в справочнике» |
| Таймаут | задержать ответ на 13 с при лимите 10 с | запрос отменён примерно по лимиту | `outcome: timeout`, `durationMs: 10004` |
| Отмена | уйти с экрана во время запроса | не превращается в ошибку пользователя | `outcome: cancel`, экран не трогается |
| Повтор | убрать отказ и нажать «Повторить» | одна активная попытка, затем успех | список загрузился, `http.start` и `http.end` парные |
| Демо-режим | на экране ошибки нажать «Показать демо-данные» | данные помечены как демонстрационные | метка «Демо-данные», 12 карточек, кнопка «Вернуться к сети» |

## Автоматические проверки

```bash
npm run typecheck   # tsc --noEmit, без ошибок
npm run lint        # eslint, 0 ошибок и 0 предупреждений
npm test            # 19 тестов, все проходят
```

Тесты закрывают разбор ответа и защиту от устаревшего ответа:

- `src/api/countries/countryDto.test.ts` — корректная запись, страна без столицы, `name: null`,
  пустое название, потерянный вложенный объект, строка вместо записи, неизвестный регион,
  отсев агрегатов, чтение метаданных, тело ошибки вместо данных, разбор населения;
- `src/shared/api/requestGuard.test.ts` — актуален только последний запрос, поздний ответ
  отбрасывается, `drop` обесценивает незавершённые запросы.

К публичному API тесты не обращаются: все данные в них — записанные образцы ответов.

## Особенности окружения

Работающий запрос с компьютера не доказывает доступность API с телефона. На физическом
устройстве `localhost` означает само устройство, поэтому в проекте используется публичный
HTTPS-адрес, а не локальный сервер.

CORS проверялся для Expo Web: World Bank API отдаёт `Access-Control-Allow-Origin: *`, поэтому
браузер запросы не блокирует. В нативном приложении браузерная модель CORS не применяется.
Проверка сертификата не отключалась.
